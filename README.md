# HARDELITE — сайт агенції

Статичний односторінковий сайт. Без збірки, без залежностей: відкривається подвійним
кліком по `index.html` і заливається на будь-який хостинг як є.

```
index.html    — уся розмітка та тексти
styles.css    — оформлення (кольори і шрифти — у самому верху файлу)
script.js     — меню, анімації, карусель, форма (контакти — у самому верху файлу)
```

---

## 1. Контакти — почніть звідси

Відкрийте `script.js`, перші 12 рядків. Замініть заглушки на справжні:

```js
const CONTACTS = {
  instagramUser: '',                                  // нік без @
  instagram:     '',                                  // https://instagram.com/ваш_нік
  instagramDM:   '',                                  // https://ig.me/m/ваш_нік
  telegram:      'https://t.me/Veronika_logvinenko',  // ✅ вже вписано
  tiktok:        '',
  email:         '',
  phone:         '+380 66 170 33 03'                  // ✅ вже вписано
};
```

Цього достатньо: усі кнопки, іконки соцмереж, пошта й телефон у футері підтягнуться
автоматично. **Порожній контакт просто зникає зі сторінки** — жодних заглушок відвідувач
не побачить. Тому Instagram, TikTok і пошту варто дописати: зараз посилання на них
приховані.

**Як працює форма.** Кнопка «Надіслати заявку» перевіряє поля, копіює заявку в буфер
обміну та відкриває Telegram — людині лишається вставити повідомлення. Щоб заявки йшли
в Instagram Direct, змініть у `script.js` рядок `const PRIMARY_CONTACT = 'telegram'`
на `'instagramDM'` (і впишіть посилання на Direct вище).
Бекенд не потрібен. Якщо згодом захочете, щоб заявки падали на пошту, це підключається
через безкоштовний Formspree — скажіть, і я переробимо.

## 2. Куди вставити фото

Зараз замість фото стоять плейсхолдери — сірі прямокутники з підписом, який кадр туди
потрібен. Кожен виглядає так:

```html
<div class="ph ph--portrait" data-ph="Портрет засновниці · вертикаль 3:4">
  <span class="ph__label">фото</span>
</div>
```

Щоб поставити справжнє фото, замініть увесь цей блок на:

```html
<img class="ph ph--portrait" src="images/veronika-hero.jpg" alt="Вероніка Логвіненко">
```

Розміри і обрізка вже задані в CSS — нічого підганяти не треба.
Складіть фото в папку `images/` поруч з `index.html`.

## 3. Екран завантаження

При відкритті сайту показується чорний екран з логотипом і смугою прогресу.
Він зникає, щойно сторінка готова, але не пізніше ніж за 1,5 секунди — щоб
відвідувач не чекав даремно. Логіка у `script.js`, функція `initLoader()`;
оформлення — у блоці «ЗАВАНТАЖЕННЯ» на початку `styles.css`.

Щоб прибрати екран завантаження зовсім, видаліть блок `<div class="loader">`
на початку `index.html`.

## 4. Нагороди (зараз вимкнені)

Блок з лавровими гілками на першому екрані прибрано. Якщо зʼявляться реальні
нагороди — скажіть, поверну: розмітка й стилі лежать в історії репозиторію.

Раніше він виглядав так:

```html
<span class="award__label">нагорода</span>          <!-- дрібний підпис зверху -->
<b class="award__title">[Назва · рік]</b>           <!-- напр. «Beauty Awards 2025» -->
<span class="award__text">[номінація або досягнення]</span>
```

Сюди підійдуть не лише премії: «100+ проєктів», «5 років у ніші», «понад 2 млн охоплень» —
будь-що, що справді є. Зайві блоки `<div class="award">…</div>` просто видаліть, решта
вирівняються самі. Якщо нагород немає взагалі — видаліть увесь `<aside class="hero__awards">`,
перший екран перебудується без них.

## 5. Інтерактивні блоки

**«Наша система»** — кнопка «Познайомитись із системою» відкриває сім слайдів.
Гортаються стрілками, крапками, клавішами ← → та свайпом. Тексти етапів —
у секції `SYSTEM` в `index.html`, логіка — `initDeck()` у `script.js`.

**«Наші послуги»** — чотири вкладки з переліком робіт. Щоб додати пункт,
допишіть `<li>` у потрібний `.scope__panel`. Логіка — `initScopeTabs()`.

**«AI чи агенція»** — таблиця порівняння. Рядок додається блоком `.vs__row`
з трьома клітинками: тема, «тільки AI», «HardElite».

## 6. Клієнти агенції

Блок «Клієнти агенції» — сітка з восьми карток-заготовок. Знайдіть у `index.html`
коментар «КЛІЄНТИ» і в кожній замініть:

```html
<span class="client__name">[@нік]</span>
<span class="client__niche">[ніша]</span>
```

Щоб поставити аватарку клієнта, замініть `<span class="client__ava"></span>` на
`<img class="client__ava" src="images/client-1.jpg" alt="@нік">`. Зайві картки просто
видаліть — сітка вирівняється сама.

## 7. Відгуки

У блоці «Відгуки про HardElite» стоять чотири порожні картки-заготовки. Тексти навмисно
не вигадані — вигадані відгуки на сайті агенції це фейк, який рано чи пізно помічають.

Знайдіть у `index.html` блок `<!-- ============ REVIEWS ============ -->` і в кожній
картці замініть:

- `[Ім'я клієнта]` — на ім'я
- `[дата]` — на дату
- текст всередині `<p class="review__body is-empty">` — на сам відгук,
  **прибравши клас `is-empty`** (він робить текст сірим курсивом)

Карток може бути скільки завгодно — просто скопіюйте `<article class="review">…</article>`
потрібну кількість разів, крапки під каруселлю порахуються самі.

## 8. Назви кейсів

Підписи в галереї зараз описують тип роботи («Особистий бренд · експерт»). Замініть їх
на реальні назви проєктів у `<span class="tile__cap">…</span>`, коли будуть узгоджені
з клієнтами.

## 9. Кольори і шрифти

Верх `styles.css`, блок `:root` — уся палітра в одному місці:

```css
--ink:    #0B0B0C;   /* майже чорний: текст і кнопки */
--paper:  #F5F3F0;   /* теплий фон сторінки */
--accent: #B5433A;   /* приглушений червоний: курсивні акценти */
--muted:  #8B8681;   /* другорядний текст */
```

Змінили один рядок — колір оновився по всьому сайту.

Шрифти: **Playfair Display** (заголовки), **Manrope** (текст), **Unbounded** (логотип).
Підключаються з Google Fonts, усі підтримують українську.

## 10. Як опублікувати

Найпростіше — [Netlify Drop](https://app.netlify.com/drop): перетягніть папку з файлами
у вікно браузера, за 10 секунд отримаєте посилання. Далі можна прикріпити свій домен.

Так само працює Vercel, GitHub Pages або звичайний хостинг через FTP — просто закиньте
`index.html`, `styles.css`, `script.js` та папку `images/` у корінь сайту.
